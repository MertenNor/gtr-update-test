# gtr-update-test

A throwaway repo for trying out the GameTextReader update check and layout browser.
Nothing in it is used by the real app.

- Releases: `v0.1.0` and a newer `v0.1.1`, for the update check.
- `layouts/`: approved layouts and `index.json`, for the layout browser.
- Issues with the label `layout submission`: layouts waiting for review.
